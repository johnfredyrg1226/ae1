# Documentación de git-wor

## Descripción

Este proyecto es de la  práctica AE1 de git y tiene como objetivo
aprender a trabajar con un repositorio colaborativo.

Durante la práctica se utilizarán ramas, issues, pull requests, resolución
de conflictos, etiquetas, releases e integración continua.

## Estructura del proyecto

El repositorio contiene los archivos necesarios para la página web,
la documentación y la configuración del proyecto.

## Control de versiones

El proyecto utiliza git para registrar los cambios realizados durante
la práctica y mantener un historial ordenado del trabajo.

## Integración continua

La documentación se comprobará automáticamente mediante un workflow
de integración continua utilizando MkDocs.
